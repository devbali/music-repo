# Music Piracy Repo
Requires ffmpeg

## Workflow
- Crawl the song to mp3
- Set the config in config.json
- Finalize Metadata for the song
- Edit around playlists
- Generate Final Folder

## Crawl
- Run `python3 crawl.py [.txt file or song link]`, or just `python3 crawl.py` and the links.txt will be used
- Youtube Music links will always work, most other platforms that are publicly accessible should also work
- You can also set up cookies for login bound things (not implemented in this repo)

## Config.json explained
- intermediate-dir: The directory the song goes to after "finalize metadata". Will be created if does not exist
- output-dir: The directory the songs go to after `gen.py` is called, to generate the final folder that is to be copied out. Will be created if does not exist. Deleted if exists every time `gen.py` is called.
- information-prompts
    - name: label for the name prompt in Finalize Metadata
    - playlist: label for the playlist tag in the .json files for the songs in the intermediate dirs
    - song-filename: the name of the mp3 in the intermediate dirs
    - info-filename: the name of the .json files for each song in the intermediate dirs
    - lyrics-filename: the name of the lyrics files for each song in the intermediate dirs
    - other-info: a list of other metadata that will be asked in finalize and put into the json file. For each item in the list:
        - name: the label of the json in the intermediate file
        - type: str (just plain string) or list (comma separated)
        - metadata-name: What metadata tag this data will go in the mp3 file
- playlist-exports: a mapping of a playlist folder to config about configuration for how every playlist is put into that folder
    - [key]: path of the folder
        - prefix-path: absolute path that the folder generated by `gen.py` will be put in this environment

## Finalize Metadata
- Run `python3 finalize.py [mp3 song path]`. You will be prompted by all of the prompts specified in the `config.json` file.
- This script will ask you for:
    - a song name (the label will be that in the config file under "information-prompts"."name")
    - a "ffmpeg suffix" to crop the recording, or add other ffmpeg transformations (press enter to copy the full song, -ss [start time] -to [end time] for a basic crop)
    - other metadata you told it to ask for

## Edit around the playlists
- Run `python3 playlist.py [name of playlist]` to edit (remove songs, add songs, change the ordering) that playlist
- If that playlist does not exist, a new one is created
- This script will list out the names of all the songs in your library, sorted by genre and song title, along with the songs currently in the playlist, sorted downwards by their "score"
- You select a song by number, and then enter a score, or nothing to remove it from the playlist
- Ctrl+D to exit (it saves every time you press enter)

## Generate final folder
- Run `python gen.py`
- This will delete the final directory if it already exists, creating it if it doesn't
- It will organize songs into folders based on genre, add all metadata according to the json files, create playlist files (.m3u) based on configuration in the `config.json` file
- You can now copy this folder into whatever device!

## Replace.py convinience tool
If you want to replace songs in the intermediate directory, you can put other mp3s in the directories, and run `replace.py`. This will replace the correctly named mp3 in the directory with whatever other mp3 is in it.
